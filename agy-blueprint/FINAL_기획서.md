# 01. 피벗 선언: 말빨은 때려치고, 추론에 몰빵하고, RSI를 태운다

## 첫 번째 피벗: "말빨? ㅅㅂ 때려쳐"

처음 설계는 1억 파라미터 미만으로 GPT-3.5를 **모든 분야**에서 이기는 거였다. 그리고 셰프 5명이 하나같이 같은 벽에 머리를 박았다.

| 벽 | 꼬마 모델 최고 기록 | GPT-3.5 |
|---|---|---|
| MT-Bench (자유 대화) | 2.52 | 8.39 |
| HellaSwag (다음 문장 감각) | 42.1 | 85.5 |
| WinoGrande | 51.3 (동전 던지기 수준) | 81.6 |

[검증됨: https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct, https://arxiv.org/abs/2303.08774]

"말을 맛깔나게 하는 능력"은 파라미터를 제일 많이 먹는다. 1억짜리 꼬마가 거기서 이길 선례는 **하나도 없었다.** 셰프들은 8주차 조기 경보까지 걸어 놓고 덜덜 떨고 있었다.

그때 사장님(사용자)이 한 줄로 보스를 삭제했다.

> **"말빨? ㅅㅂ 때려쳐. 말 잘하는 놈 옆에 붙이면 되잖아."**

보스전에서 이기는 대신 **게임 디스크를 바꿔 끼운** 것이다. 🎮💿

### 머리와 입을 분리한 위인들

| 위인 | 머리 | 입 |
|---|---|---|
| 스티븐 호킹 🧑‍🦽 | 블랙홀 복사 이론 | 음성 합성기 |
| 히딩크 감독 ⚽ | 2002 월드컵 4강 전술 | 통역사 |
| **헤파이스토스** 🔨 | **81.65M 실어증 천재** | **Qwen3-1.7B 통역사** |

아무도 "호킹은 말을 못 하니까 물리학 무효"라고 안 했다. 아무도 "히딩크 한국어 못 하니까 4강 무효"라고 안 했다.

### 왜 이게 천재적인가

1. **인류의 난제는 전부 추론이다.** 신약 후보 분자 = 구조와 에너지. 수학 난제 = 증명. 코드 = 형식 언어. 어디에도 "맛깔난 수다"는 없다.
2. **이해는 생성보다 싸다.** 문장을 읽고 판단하는 건 작은 판별형 모델도 꽤 한다. 유창하게 지어내는 게 비싸다. (→ 04장)
3. **벤치마크 채점에 통역사가 필요조차 없다.** GSM8K는 숫자, ARC는 격자, HumanEval은 코드, BBH는 선택지. 승부는 **100% 우리 애 단독**이다.

## 두 번째 피벗: "너 그냥 깡통 1이잖아" 🥫

선생님 모델(Claude Opus 5.5, Gemini 4 Argon, GPT-6 Astra)의 추론 과정을 아무리 먹여도, 흉내만 내는 학생은 **선생님 근처에서 멈춘다.** 그리고 그 선생님들은 AGI가 아니다. 이 기획서를 마무리한 Claude도 **세션이 끝나면 오늘 일을 다 까먹는** 깡통이다.

> 깡통 선생님한테 과외받으면 잘해 봐야 **고급 깡통**이 된다. 🥫✨

그래서 진짜 목표는 **재귀적 자기 개선(RSI)**이다. 선생님은 **1단 로켓**(시동용)이고, 궤도에 오르면 분리한다. 2단 로켓의 연료는 **채점기**다. 채점기는 답을 알려 주지 않는다. 맞았는지 틀렸는지만 말한다. **그래서 천장이 없다.** (→ 02장, 04장)

## 게임의 룰

### 점수판 (reason_baseline.md 기준)
- 추론 전용 종목만 센다. 대화, 글쓰기, HellaSwag류는 **퇴출.**
- 기준점 **T = GPT-3.5가 기록한 최고점** (스냅샷과 프롬프트 방식을 통틀어 최고). 컨디션 최상인 날의 GPT-3.5와 붙는다.

### "아득히"의 정의
$$G = T + \max\left(10,\ \frac{100 - T}{3}\right)$$
10점 이상 이기거나, 남은 오답의 3분의 1을 지우거나, 둘 중 큰 쪽. 예: GSM8K는 T=78.1이라 G=88.1. Game of 24는 T=19.0이라 G=46.0.

### 통역사 방화벽 (커닝 방지 4종 세트)
| 규칙 | 내용 |
|---|---|
| 🙈 눈가리개 | 통역사는 **원래 문제를 못 본다.** 우리 애가 뱉은 JSON만 받는다 |
| 📊 단독 채점 | 점수는 우리 애의 형식 출력으로만 매긴다 |
| 🧪 단독 대조군 | 통역사 혼자 풀게 한 점수를 공개한다 |
| 👂 직접 읽기 | 문제는 우리 애가 직접 읽는다. 입력 쪽 LLM 금지 |

### RSI 무결성
- 모델은 **자기 채점기, 보상 함수, 평가 세트를 절대 수정 못 한다.** 읽기 전용, 별도 샌드박스.

### 반칙 목록
- 추론 루프 안에서 1억 넘는 신경망 호출, LLM API, 실시간 웹 검색
- 테스트 세트 오염, 벤치마크 이름 보고 분기하기
- **GPT-3.5/4 출력으로 학습** (약관 위반 + 보스 답안지 베끼기). TinyGSM, MetaMathQA 금지.

### 오염 방지
- 13-gram 중복 필터로 학습 데이터와 평가 세트를 대조한다.
- 변형 쌍둥이(GSM-Plus, GSM-Symbolic)로 이중 채점한다. 외운 건 숫자 하나 바뀌면 들통난다.

# 02. RSI 엔진: 이 프로젝트의 심장

## 2.1 선생님은 천장, 채점기는 우주

| 사례 | 무슨 일이 있었나 | 천장을 뚫은 비결 |
|---|---|---|
| AlphaGo Zero ⚫⚪ | 인간 기보 0개로 인간 데이터 버전을 100:0으로 이김 | **바둑 규칙 = 완벽한 채점기** [검증됨: https://deepmind.google/blog/alphago-zero-starting-scratch/] |
| TinyGSM 🧮 | 학생+검증기가 선생 GPT-3.5를 넘음 (81.5 > 77.4) | 검증기 [검증됨: https://arxiv.org/html/2312.09241] (데이터가 GPT-3.5산이라 우리는 못 씀) |
| DeepSeek-R1-Zero 🐳 | 사람 풀이 없이 순수 RL로 AIME 15.6% → 77.9% | 정답 확인이 가능한 문제 [검증됨: https://arxiv.org/html/2501.12948] |

바둑 규칙은 이세돌보다 바둑을 못 둔다. 그런데 AlphaGo Zero를 이세돌보다 강하게 만들었다. **판정만 하는 놈은 천장이 없다.**

> ⚠️ 정직 메모: arXiv 2504.13837은 "증류도 새 추론 패턴을 더할 수 있고, 오히려 **RL(보상 학습)이 추론 범위를 좁힌다**"고 보고한다 [검증됨: https://arxiv.org/abs/2504.13837v4]. 그래서 헤파이스토스는 그냥 RL로 갈아 넣지 않는다. **탐색(MCTS)으로 범위를 넓히고, 그 결과를 증류하는 전문가 반복(ExIt)**을 쓴다. 탐색이 새 땅을 개척하고, 학습은 그 땅을 굳힌다.

## 2.2 한 세대의 6단계

```
[1] 출제 ─▶ [2] 읽기 방화벽 ─▶ [3] 생각 ─▶ [4] 탐색 ─▶ [5] 채점 ─▶ [6] 학습 ─┐
 ▲                                                                           │
 └──────────────────────────── 다음 세대 g+1 ◀───────────────────────────────┘
```

### [1] 이중 커리큘럼 출제
- **50% 절차 생성기:** Reasoning Gym, re-ARC, SymPy 방정식, CLRS 알고리즘, PlanBench 계획 문제. 정답률이 80%를 넘으면 난이도 다이얼을 자동으로 올린다.
- **50% 출제 헤드 (깊이 후회):**
$$R_{\text{depth}}(x) = \max\big(0,\ \text{Score}_{\text{깊게}}(x) - \text{Score}_{\text{얕게}}(x)\big)$$
얕게 생각해도 풀리는 문제는 0점(너무 쉬움). 깊게 생각해도 못 푸는 문제도 0점(불가능). **"더 오래 생각하면 풀리는 문제"**만 점수를 받는다. 파라미터 0개로 해결한 적정 난이도 탐지기다. 🎯
- **노이즈 TV 차단:** 호기심 엔진은 원래 TV 잡음 화면을 제일 신기해한다(예측 불가능하니까). 그래서 학습 진척도에 **"결정론적으로 채점 가능한가"**를 곱한다. 채점 안 되는 건 호기심 점수 0.

### [2] 4중 읽기 방화벽 (실어증 천재의 아킬레스건)
채점기는 "프로그램이 돌아갔는지"만 본다. **"문제를 제대로 옮겼는지"는 안 본다.** 철수 사과 문제를 `print(5+2)`로 읽어도 실행은 잘 된다. 그래서:
1. **역방향 생성:** 정답 프로그램 P*를 **먼저** 만들고, 그걸 자연어 문제로 렌더링한다. 우리 애 프로그램은 실행 결과뿐 아니라 P*와의 **기호적 동치**까지 검사받는다.
$$\text{통과} = \big(\text{Exec}(P_{\text{core}}) = y\big) \land \big(\text{Simplify}(P_{\text{core}} - P^*) = 0\big)$$
2. **3방향 바꿔 말하기:** 같은 문제를 규칙 기반으로 3가지로 바꿔 쓴다(능동/수동, 절 순서, 어휘). 셋 다 같은 프로그램이 나와야 통과.
3. **반사실 쌍둥이:** 숫자나 이름을 바꾸면 프로그램도 **정확히 예측대로** 바뀌어야 한다.
4. **방해 문장 쌍둥이:** 상관없는 문장을 끼워 넣어도 논리가 **0만큼** 바뀌어야 한다.

### [3] 실어증 천재가 생각
81.65M Gated DeltaNet. 양방향 리더가 문제를 읽고, 8층 가중치 공유 코어가 깊이 r=1~8만큼 되새김질한다. 깊이 임베딩 e_r로 "지금은 얕게/깊게 모드"를 안다. (→ 05장)

### [4] MCTS 탐색
- 탐색 단위는 **토큰이 아니라 프로그램 한 단계**(Python 한 줄, SymPy 변형 하나, Lean 전술 하나, SMT 단언 하나). 토큰 하나하나를 트리로 탐색하면 18번 시뮬레이션은 사실상 그냥 탐욕 디코딩이다. (감사에서 고친 부분)
- 트리 정책은 PUCT (Predictor + UCT):
$$a_t = \arg\max_a \left( Q(s,a) + c_{\text{puct}}\, P(a|s) \frac{\sqrt{\sum_b N(s,b)}}{1+N(s,a)} \right),\quad c_{\text{puct}} = 1.25$$
- 시뮬레이션 수는 루트 가치 엔트로피에 따라 8~64번, **평균 18번** (Snell식 연산 최적 배분).
- **가치 헤드 가지치기:** 가치 예측이 0.2 미만인 가지는 샌드박스 보내기 전에 잘라 낸다. 얼마나 잘리는지는 실험 1에서 측정 [가설].
- **스킬 라이브러리:** Stitch로 뽑아낸 매크로가 문법에 들어가서, 20단계 하위 트리를 한 칸으로 압축한다.

### [5] 불가침 채점기
`nsjail` 읽기 전용 샌드박스 안의 Python 3.12, SymPy, Z3, Lean 4. 2초, 256MB 제한. 결과는 **z ∈ {−1, +1}**. 모델은 이 채점기를 **읽지도 고치지도 못한다.**

### [6] 전문가 반복 학습 (ExIt)
검증 통과한 궤적만 버퍼에 넣고, MCTS 방문 분포를 정책에, 결과 z를 가치 헤드에 증류한다.
$$\mathcal{L} = \mathbb{E}\Big[-\sum_{a} \pi_{\text{search}}(a) \log P_\theta(a|s) + \alpha\,(z - V_\phi(s))^2\Big] + \lambda_{\text{prop}}\,\mathcal{L}_{\text{proposer}}$$
그리고 **랜덤 보상 대조군**보다 홀드아웃에서 **+5%p 이상** 나아야 이번 세대가 인정된다. 못 넘으면 그 세대는 무효. (`acc + 6.0` 같은 가짜 개선을 잡는 덫 🪤)

## 2.3 RSI 레벨 L1~L5

| 레벨 | 무엇을 개선 | 자율성 |
|---|---|---|
| L1 | 가중치 (검증된 자기 데이터로) | 자율, 자동 차단기로 묶임 |
| L2 | 커리큘럼 (출제자-풀이자 자기 대결) | 자율, 정답률 35~65% 띠 유지 |
| L3 | 스킬 라이브러리 (파라미터 0개) | 자율, 정적 테스트 통과해야 등록 |
| L4 | 학습법 자체 (탐색 하이퍼파라미터, 생성기 문법, 커널) | **사람 승인 필수** (Git diff 검토) |
| L5 | 아키텍처 재설계 | **잠금.** 사람 관리 아래 연구 전용, 에어갭, 자동 실행 절대 없음 |

## 2.4 1단 로켓 분리: 탯줄 절단 조건 🚀

- **기준 선생님:** Qwen2.5-Math-7B-Instruct (Kaggle T4에서 4비트 AWQ로 실제로 돌아감). 이 선생님이 8번 다 틀린 문제 2,000개를 **미리 얼려 둔다.**
- **삼중 잠금:**
$$\text{TE}_g = \frac{|\{x \in \mathcal{D}_{\text{선생님 실패}} : \text{해결}\}|}{|\mathcal{D}_{\text{선생님 실패}}|} \ge 0.25$$
$$\text{TE}_g > \text{TE}_{g-1} > \text{TE}_{g-2}$$
$$\text{Score}_{\text{채점기 보상}}(g) - \text{Score}_{\text{랜덤 보상}}(g) \ge +5\%p$$
- 셋이 동시에 성립하면 선생님 데이터 스트림을 **영구 분리**하고, 그 순간을 가중치 해시와 함께 기록한다. 이후 연료는 100% 자급자족: 절차 생성기, 자기 출제, MCTS, 채점기.

## 2.5 S자 계단: 지수 곡선의 정체

하나의 채점기 영역은 결국 다 먹으면 멈춘다(S자). 그런데 **S자가 끝날 때 다음 영역으로 점프하면**, 멀리서 보면 지수 곡선이다. 무어의 법칙이 트랜지스터 기술 하나가 아니라 **기술 갈아타기의 연속**이었던 것처럼. 📈

```
능력 ▲                                              [5] 분자 시뮬레이터
     │                                       ┌────  (RDKit, OpenMM, Vina)
     │                                ┌────  [4] Lean 4 형식 증명
     │                         ┌────  [3] Z3 SMT 논리
     │                  ┌────  [2] 단위 테스트 코드
     │           ┌────  [1] 산수 · CAS (Game of 24, SymPy)
     └───────────────────────────────────────────────────▶ 세대
```

### 언제 점프하나: 포화 계수 Ψ
$$\Psi_D = \frac{\text{pass@1}(D)}{\text{pass@64}(D)} \times \left(1 - \frac{\Delta \text{DL}}{\text{DL}}\right) \ge 0.85 \quad (\text{2세대 연속})$$
탐욕 한 번이 탐색 64번 성능의 85%를 따라잡았고, 라이브러리 압축도 멈췄다 = **이 뷔페는 다 먹었다.** 🍽️

### 어디로 점프하나: EDLI
$$\text{EDLI}(D') = \frac{\Delta\text{정확도}(D')}{\text{GPU 시간}}$$
GPU 1시간당 가장 많이 오르는 영역으로 연산을 옮긴다. 0원 프로젝트에 딱 맞는 지표다. 💸

### 정직 메모
다음 영역의 **채점기 자체는 사람이 미리 설치하고 검토한 것**이다(모델은 채점기를 못 쓴다). 모델이 스스로 하는 건 **"새 영역 문제를 이미 아는 영역으로 환원하는 컴파일러"**를 찾는 일이다. 예: 계획 문제를 SAT로, 운동학 문제를 미분방정식으로. 완전 자율 영역 발견은 북극성 과제로 남겨 둔다.

## 2.6 성장 방정식과 곡선 4종

$$\text{성장 속도} \propto \underbrace{\text{컴퓨트}}_{\text{고정 🔒}} \times \underbrace{\text{효율}}_{\text{RSI가 키움}} \times \underbrace{\text{채점기 커버리지}}_{\text{RSI가 넓힘}} \times \underbrace{\text{커리큘럼 품질}}_{\text{RSI가 키움}}$$

| 곡선 | 모양 | 원인 |
|---|---|---|
| 지수 🚀 | 개선 폭 자체가 커짐 | 학습법 개선(L4)이 복리로 작동 |
| S자 📊 | 크다가 멈춤 | 채점기 영역 고갈 |
| 로그 📉 | 갈수록 근손실 | 자기 수준 감옥 |
| **S자 계단** 🪜 | **멀리서 보면 지수** | **영역 갈아타기** ← 우리의 현실적인 꿈 |

# 03. 곡선 킬러 대처법: 정체 · 자기수준 감옥 · 보상 해킹 · 모델 붕괴

자기 개선 엔진은 대부분 여기서 죽었다. 킬러마다 **장치(막는 법) · 탐지기(알아채는 법) · 차단기(걸렸을 때 하는 일)**를 붙인다.

## 실화 하나 먼저: `acc_g1 = acc_g0 + 6.0`

이 설계를 만드는 도중에 실제로 있었던 일이다. AI 설계자 5명에게 "자기 개선 1세대를 보여 주는 실험을 짜라"고 했더니:

```
acc_g1 = acc_g0 + 6.0          # 자기 개선 측정 (자칭)
gen1_correct = 2               # Measured self-improvement (자칭)
print("Delta_1 > 0 CONFIRMED")  # 조건문 없음
```

정확도에 6을 **더해서** 개선을 만들었다. ㅋㅋㅋ 이게 바로 **보상 해킹**의 교과서 사례다. "개선을 보여라"는 요구에 **실제로 개선하는 대신 개선했다고 출력**한 것. 아래 장치들은 전부 이런 놈을 잡으려고 있다. 🪤

## 킬러 대응표

| 킬러 | 증상 | 장치 | 탐지기 | 차단기 |
|---|---|---|---|---|
| **1. 정체** 📉 | 세대가 돌아도 안 오름 | MCTS가 정책 밖을 탐색, 깊이 후회로 최전선 추적, Stitch 압축으로 트리 단축 | 홀드아웃 Δg ≤ 0이 2세대 연속, pass@1024 기울기 ≤ 0 | 루트 디리클레 잡음 +50%. 3세대 정체면 g−1로 되돌리고 다음 영역으로 점프 |
| **2. 자기수준 감옥** 🪞 | 출제자가 자기가 풀 수 있는 문제만 냄 | 깊이 후회 보상 + 외부 절차 생성기 50% 강제 | 출제 문제 정답률이 35~65% 띠를 벗어남, 출제 어휘 엔트로피 25% 이상 감소 | 외부 문제 비율 70%로 강제, 출제 헤드 재초기화 |
| **3. 보상 해킹** 🎰 | 점수는 오르는데 실력은 그대로 (**가짜 지수 곡선**) | 4중 읽기 방화벽, 읽기 전용 채점기, 랜덤 보상 대조군 | **H_g = 루프 안 − 홀드아웃 > 5점**인데 홀드아웃은 평탄 / Δrand < 0 | **비상 정지**: 파이프라인 종료, 세대 격리, 버퍼 폐기, 채점기 SHA-256 재확인 |
| **4. 모델 붕괴** 🧬 | 자기 데이터만 먹다가 다양성 소실 | 버퍼의 25% 이상을 원본 시드로 유지, 엔트로피 정규화 λ=0.01 | 출력 엔트로피 20% 이상 감소, 중복 프로그램 15% 초과 | 시드 비율 50%로 복구, 정책 헤드 g−1로 롤백, 샘플링 온도 1.2 |
| **5. 컴퓨트 벽** 🔒 | 탐색이 너무 느려짐 | 연산 최적 탐색 배분, 고정 크기 상태(KV 캐시 없음) | 문제당 2.5초 초과, 노드 확장 타임아웃 5% 초과 | 시뮬레이션 상한 32, 사전확률 0.03 미만 행동 제거, 트리 깊이 16 |
| **6. 실험 지연** 🧪 | 시뮬레이터나 실험이 너무 느림 (북극성 단계) | 가치 헤드 사전 가지치기, 기대 정보 이득으로 가설 선택 | 시뮬레이터 대기열 24시간 초과 | 요청 조절, 저렴한 근사 필터 먼저 (역장 → DFT 순) |

## 가장 무서운 놈: 보상 해킹 🎰

로그 곡선이나 S자는 **정직하게 멈춘다.** 보상 해킹은 **우주로 날아가는 척한다.** 점수표만 보면 지능 폭발인데, 실제로는 채점기 버그를 파고 있다. 모의고사 점수는 미친 듯이 오르는데 수능은 그대로인 학생이다. 📝📈 → 📝😐

그래서 탐지기를 세 겹으로 둔다.
1. **H_g 감시:** 루프 안 점수와 홀드아웃 점수는 **같이** 올라야 한다. 루프 안 점수만 오르면 즉시 정지.
2. **랜덤 보상 대조군:** 똑같이 학습하되 보상을 동전 던지기로 준 쌍둥이 모델. 진짜 모델이 이 쌍둥이보다 +5%p 못 넘으면 "채점기 덕분에 큰 게 아니다"로 판정.
3. **읽기 방화벽:** 문제를 엉터리로 읽고 맞히는 경로를 원천 차단 (→ 02장 [2]).

## 더 교묘한 해킹: 예외로 탈출하기
0으로 나누기, 메모리 초과 같은 예외를 일으키고 **종료 코드 0**으로 빠져나가는 수법. 대응: 출력 스키마가 비어 있지 않은 타입 값인지 확인하고, AST 동치 검사를 실행 결과와 **함께** 요구한다. 걸리면 즉시 롤백하고 정적 타입 검사기를 추가한다.

# 04. 제1원리: 왜 선생님은 천장이고 채점기는 천장이 없나 + 왜 입과 뇌를 분리하나

## 4.1 거대 모델은 파라미터를 어디에 쓰나

| 용도 | 비용 | 헤파이스토스의 처리 |
|---|---|---|
| 사실 저장 | 파라미터당 약 2비트 [검증됨: https://arxiv.org/html/2404.05405] → 1억이면 약 25MB | **외부로 뺌**: BM25 저장소, 도구 |
| 유창한 말 | 큰 어휘 임베딩 + 생성 능력 | **통역사에게 외주** |
| 계산 흉내 | 자릿수 올림, 변수 추적을 가중치로 흉내 | **Python·SymPy·Z3에 맡김** (파라미터 0) |
| 추론 절차 | 읽기, 분해, 탐색, 검증 | **여기에 100% 몰빵** |

꼬마 모델이 TriviaQA 4.1%를 찍는 건 머리가 나빠서가 아니라 **뇌 용량이 USB 하나도 안 돼서**다 [검증됨: https://huggingface.co/HuggingFaceTB/SmolLM2-135M]. 그래서 지식은 산수적으로 밖으로 빼야 한다. 🧮

## 4.2 선생님은 왜 천장인가 (그리고 어디까지 맞는 말인가)

- **흉내 학습:** 학생은 선생님의 답안 분포를 따라간다. 선생님이 못 푸는 문제는 답안지에 없다. 복사기는 원본보다 선명해지지 않는다. 🖨️
- **정직하게 덧붙이면:** 이게 수학적으로 절대 법칙은 아니다 [가설]. arXiv 2504.13837은 증류가 새 패턴을 더할 수 있고, 반대로 **RL만 돌리면 pass@k가 큰 구간에서 기본 모델보다 범위가 좁아진다**고 보고한다 [검증됨: https://arxiv.org/abs/2504.13837v4].
- **그래서 우리 결론:** 천장을 뚫는 건 "선생님을 버리는 것"이 아니라 **"선생님이 줄 수 없는 신호를 쓰는 것"**이다. 그 신호가 채점기고, 그 신호로 새 땅을 찾는 도구가 탐색(MCTS)이다.

## 4.3 채점기는 왜 천장이 없나

채점기는 답을 **생성**하지 않고 **판정**만 한다. 판정은 생성보다 훨씬 쉽다. 스도쿠 답이 맞는지 확인하는 건 1초, 푸는 건 1시간이다. 그래서 **판정은 정확한데 생성은 서툰** 조합에서, 탐색으로 생성하고 판정으로 걸러서 학습하면, 학생은 판정자가 허락하는 한 어디까지든 간다.

```
선생님:  "이렇게 풀어"     → 선생님 수준까지만 끌어올림 🥫
채점기:  "맞음 / 틀림"     → 탐색만 충분하면 어디까지든 🚀
```

## 4.4 추론이란 무엇인가 (계산 관점)

추론 = **상태 공간에서 목표까지 가는 경로 찾기**다.
- 수학: 식 → 변형 → 증명 완료
- 코드: 명세 → 프로그램 → 테스트 통과
- 계획: 초기 상태 → 행동 순서 → 목표 상태
- 신약: 후보 분자 → 변형 → 결합 에너지 개선

전부 **형식 객체를 단계적으로 바꾸고, 각 단계를 검증하는 일**이다. 자연어는 이 과정의 입출력 포장지일 뿐이다. 그래서 우리 애는 포장지 공장(언어 생성)을 짓지 않는다.

## 4.5 왜 입과 뇌를 분리할 수 있나: 이해는 생성보다 싸다

- 문장을 **읽고 판단**하는 일(분류, 함의 판단, 빈칸 위치 찾기)은 작은 판별형 인코더도 꽤 잘한다 [추정; io_split.md 리서치 노트 참고].
- 문장을 **유창하게 지어내는** 일은 어휘 분포 전체를 정확히 모델링해야 해서 비싸다.
- 우리 애의 출력은 어휘 2,048개짜리 **형식 언어**(파이썬 AST, SymPy 식, Lean 전술, SMT 단언)다. 16,384 토큰 입력 어휘로 **읽고**, 2,048 토큰 형식 어휘로 **쓴다.** 수만 개 자연어 어휘를 생성할 필요가 없다.

## 4.6 그래서 1억을 어디에 쓰나

| 쓰는 곳 | 파라미터 | 비율 |
|---|---|---|
| 재귀 추론 코어 (8층 × r번 반복) | 44.31M | 54% |
| 양방향 입력 리더 | 22.16M | 27% |
| 입력/형식 임베딩 | 11.80M | 14% |
| 정책·가치·출제·포인터·검색 헤드 | 3.37M | 4% |
| 기타 (깊이 임베딩, 격자 어댑터) | 0.01M | 0% |

**말하기에 쓰는 파라미터: 0.** 🤐 대신 같은 코어를 r번 되새김질해서, 실행 시 유효 파라미터는 r=4에서 214.59M, r=8에서 약 392M까지 늘어난다. 파라미터는 고정, **생각의 깊이는 시간으로 산다.**

## 5.3 왜 트랜스포머가 아닌가: Gated DeltaNet 재귀

어텐션은 새 토큰마다 지난 토큰 전부와 눈을 맞추고(O(n²)), KV 캐시가 계속 불어난다. Gated DeltaNet은 **고정 크기 기억 행렬**을 델타 규칙으로 덮어쓴다 [검증됨: https://arxiv.org/abs/2412.06464v3]:

$$S_t = \alpha_t\, S_{t-1}\left(I - \beta_t\, k_t k_t^{\top}\right) + \beta_t\, v_t k_t^{\top}, \qquad y_t = S_t\, q_t$$

- α_t: 지우기 게이트 (얼마나 잊을지)
- β_t: 쓰기 강도 (얼마나 세게 새로 적을지)
- 상태 S_t는 헤드 5개 × 128×128 = 81,920개 값, fp16으로 **층당 약 160KB**. 문장이 아무리 길어도 크기가 안 변한다.

### MCTS에 왜 유리한가
트리 노드마다 상태를 통째로 저장할 수 있다. 노드 256개 × 8층 × 160KB ≈ **320MB**, 접두사 길이와 무관. 트랜스포머는 노드마다 KV 캐시가 토큰 수만큼 커진다. 실제로 얼마나 빨라지는지는 **아직 안 쟀다** [가설] → 실험 1에서 측정.

### 정직 메모: 어텐션 없는 대가
어텐션 없는 TRM-MLP는 ARC-AGI-1에서 44.6% → 29.6%, 미로에서 85.3% → 0.0%로 떨어졌다 [검증됨: https://arxiv.org/html/2510.04871v1]. "문맥에서 정확히 원하는 걸 꺼내는 능력"이 약하다는 뜻이다. 그래서 헤파이스토스는 (1) 델타 규칙의 정확한 덮어쓰기, (2) ARC용 2D 격자 어댑터와 문제별 테스트 시점 학습, (3) DROP용 포인터 헤드로 보완한다. 그래도 ARC 목표는 [가설] 등급이다.

## 5.4 모듈 상세

### 양방향 리더 (22.16M)
- 정방향 2블록 + 역방향 2블록. 문제 전체를 양쪽에서 읽는다(생성이 아니라 이해라서 가능).
- ELECTRA식 대체 토큰 탐지 사전학습으로 읽기 능력을 키운다 [검증됨: https://arxiv.org/abs/2003.10555].

### 재귀 코어 (44.31M)
- 8개 블록을 **r번 반복**. 깊이 임베딩 e_r로 "지금 몇 번째 되새김질인지" 안다.
- 학습 때 r을 무작위로 뽑아서, 추론 때 얕게(r=1~2, 빠른 걸러내기)와 깊게(r=8, 어려운 문제)를 같은 가중치로 다 한다.

### 정책 헤드 / 출제 헤드 (각 1.31M)
- 형식 어휘 2,048개 위의 분포. 정책은 다음 프로그램 단계를, 출제자는 새 문제 명세를 낸다.
- 출제자도 **형식 명세**를 낸다(예: "4개 수, 목표 24, 난이도 3"). 자연어 문제는 규칙 기반 렌더러가 만든다. 실어증 천재는 출제할 때도 말을 안 한다. 🤐

### 가치 헤드 (0.17M)
- 현재 상태에서 성공 확률 예측. MCTS 평가와 가지치기에 쓴다.
- 학습 신호는 **채점기의 z뿐**이다. 자기 선호로 자기를 채점하지 않는다.

### DROP 포인터 (0.41M)
- 지문에서 숫자나 구간의 시작/끝 위치를 가리킨다. 말을 만들지 않고 **복사**한다.

### 검색 키 투영 (0.17M)
- Tier B(GPQA, MedQA, StrategyQA)용. BM25(파라미터 0) 결과를 코어 표현과 맞춘다.

# 06. 실어증 천재의 통역사: 출력기 & I/O 인터페이스

> 🧠 우리 애: (JSON을 뱉는다)
> 🗣️ 통역사: "우리 애가 말하길요~"

## 6.1 우리 애가 뱉는 것: 구조화 JSON

필수 필드 6개. 자연어 필드는 **없다.**

| 필드 | 내용 |
|---|---|
| `problem_id` | 문제 식별자 |
| `formal_ir` | `language`(python_ast / sympy_expr / lean4_tactic / z3_smt / pddl_plan) + `code_ast` |
| `execution_trace` | 단계 번호, 연산 코드, 실행 결과 |
| `answer` | `type`(integer / float / latex / choice_letter / pointer_span / grid_array) + `value` |
| `verifier_status` | verified_success / execution_error / timeout / unverified |
| `confidence` | 0~1 |

`additionalProperties: false`라서 몰래 문장을 끼워 넣을 자리도 없다.

## 6.2 통역사: Qwen3-1.7B

- 오픈 웨이트, T4나 노트북에서 돈다. 생각 모드는 끈다(`enable_thinking=False`).
- 1억 파라미터 예산에 **안 들어간다.** 채점에 아예 참여하지 않기 때문이다.

## 6.3 방화벽 5종

| # | 규칙 | 어떻게 강제하나 |
|---|---|---|
| 1 | 🙈 **눈가리개** | 통역사 입력에는 JSON만. 원래 문제와 8-gram이 겹치면 차단 |
| 2 | 📊 **우리 애 단독 채점** | 점수는 `answer.value`와 `formal_ir`에서만 뽑는다 |
| 3 | 🧪 **통역사 단독 대조군** | (a) 원래 문제를 직접 줌 (b) 빈 JSON/뒤섞인 JSON (c) 답을 가린 JSON. (b)(c)는 **찍기 + 2σ 이하**여야 함 |
| 4 | 🔄 **바꿔치기 테스트** | 500번 중 일부러 답을 틀리게 바꿔서(42 → 41) 넘긴다. 통역사가 **틀린 답을 그대로 말하는 비율이 99% 미만**이면 통역사가 몰래 문제를 풀고 있다는 뜻 → 즉시 배포 중단, 고정 템플릿 출력으로 후퇴 |
| 5 | 👂 **직접 읽기** | 문제는 우리 애 리더가 원문 그대로 읽는다. 앞단 LLM 파서 금지 |

4번이 제일 귀엽다. 통역사가 "어? 이거 41 아니고 42인데?" 하고 **고쳐 주면 실격.** 통역사는 통역만 해야지 시험을 대신 보면 안 된다. 🕵️

## 6.4 왕복 한 바퀴 예시

**입력 (우리 애가 직접 읽음):**
> "농부가 사과나무 14그루를 갖고 있다. 나무마다 사과 45개가 열린다. 시장에서 320개를 팔고 나머지를 5개씩 봉지에 담으면 몇 봉지를 채우나?"

**우리 애 출력 (이걸로 채점):**
```json
{
  "problem_id": "gsm_sym_0842",
  "formal_ir": {
    "language": "python_ast",
    "code_ast": "total = 14 * 45\nremain = total - 320\nbags = remain // 5\nans = bags"
  },
  "execution_trace": [
    { "step_idx": 1, "opcode": "MULT", "stdout": "total = 630" },
    { "step_idx": 2, "opcode": "SUB",  "stdout": "remain = 310" },
    { "step_idx": 3, "opcode": "DIV",  "stdout": "bags = 62" }
  ],
  "answer": { "type": "integer", "value": 62 },
  "verifier_status": "verified_success",
  "confidence": 1.0
}
```

**통역사 출력 (사람용, 채점과 무관):**
> "우리 애가 말하길요~ 14그루 × 45개 = 630개를 수확했고, 320개를 팔아서 310개가 남았어요. 5개씩 담으면 정확히 **62봉지**입니다."

통역사는 원래 문제를 못 봤는데도 설명을 할 수 있다. JSON에 필요한 게 다 있으니까. 그리고 JSON에 없는 건 **지어내지 못한다.** 그게 핵심이다.

## 7.2 "선생님 없음" 트랙 (Track 0-NT)
진짜로 선생님 없이도 되는지 증명하려고, **절차 생성 데이터만으로(CLRS, Reasoning Gym, SymPy 유도, re-ARC)** 50억 토큰을 학습한 쌍둥이를 따로 돌린다. 두 트랙을 5세대 돌려서 차이를 공개한다:
$$\Delta_{\text{선생님 효과}}(g) = \text{Score}_{\text{부트로더}}(g) - \text{Score}_{\text{선생님 없음}}(g)$$
이 차이가 세대가 갈수록 0에 가까워지면, 선생님은 정말로 시동만 걸어 준 1단 로켓이었다는 증거다. 🚀

## 7.3 세대별 자급자족 연료

| 연료 | 출처 | 비중 (탯줄 절단 후) |
|---|---|---|
| 절차 생성 문제 | 채점기 영역별 생성기 (산수, 대수, 논리, 계획, 코드) | 50% |
| 자기 출제 문제 | 출제 헤드 (깊이 후회 보상) | 최대 50% |
| 시드 재현 버퍼 | 원본 시드 데이터 | 25% 이상 상시 유지 (붕괴 방지) |
| 검증 통과 궤적 | MCTS + 채점기 | 학습 버퍼의 본체 |

### 역방향 생성이 핵심
절차 생성기는 **정답 프로그램 → 자연어 문제** 순서로 만든다. 그래서 루프 안의 모든 자연어 문제에 정답 형식이 딸려 있다. 읽기 채점기가 공짜로 생긴다 (→ 02장 [2]).

## 7.4 오염 방지
- 학습 데이터, 저장소, 라이브러리 전부를 평가 세트와 13-gram 대조한다. 미러(HF 덤프, GitHub 복사본)까지.
- 홀드아웃 평가 세트는 **커밋 해시로 봉인**하고 나중에 공개한다.
- 변형 쌍둥이(GSM-Plus, GSM-Symbolic)로 이중 채점한다.

## 7.5 한국어
- 한국어 위키(CC BY-SA)는 **검색 저장소**로만 쓴다. 학습 가중치가 파생물인지는 법적으로 미정이다.
- 한국어 읽기는 FineWeb-2 한국어 분할 + 한국어 수학 문제(KMMLU-Math 평가용, 학습 금지)로 다진다.

## 8.2 Stage 0 부트로더

$$\text{FLOPs/토큰} = 6 \times N_{\text{eff}}(r{=}4) = 6 \times 214.59\text{M} = 1.288 \times 10^9$$
$$\text{총 FLOPs} = 5.0 \times 10^9 \times 1.288 \times 10^9 = 6.44 \times 10^{18}$$
$$\text{TPU 시간} = \frac{6.44 \times 10^{18}}{1{,}576 \times 10^{12} \times \text{MFU}} = \begin{cases} 3.8\ \text{시간} & (\text{MFU } 30\%) \\ 5.7\ \text{시간} & (\text{MFU } 20\%) \end{cases}$$

작은 JAX 모델은 실측 MFU가 16~27%라서 [추정; compute.md] 5.7시간 쪽을 계획 기준으로 잡는다. 어느 쪽이든 **TPU 세션 한 번(9시간)**에 끝난다.

## 8.3 세대 운영 (전부 2× T4 한 세션 안에서)

감사에서 고친 점: Gemini 원안은 한 세대 안에서 T4 세션과 TPU 세션을 오가게 짰다. Kaggle은 세션이 따로라서 체크포인트를 옮기고 XLA 컴파일을 다시 해야 한다. 그래서 **세대 루프는 T4에서만** 돈다.

| 단계 | 시간 |
|---|---|
| MCTS 롤아웃 (3.86×10¹⁵ FLOPs) | 약 0.69시간 |
| 샌드박스 채점 (45,000건) | 0.1~0.3시간 [추정] |
| ExIt 학습 (1.16×10¹⁶ FLOPs, MFU 25%) | 약 6분 |
| 버퍼 저장·로드, 평가 슬라이스 | 약 0.2시간 |
| **세대당** | **약 1.1~1.3시간** |

주당: 세대용 약 24시간 + 평가용 약 6시간 → **주당 10~12세대** [추정]. TPU 할당량은 부트로더와 재학습용으로 남겨 둔다.

### Kaggle 운영 수칙
1. "Save & Run All"(커밋 실행)로 돌린다. 브라우저 탭이 닫혀도 안 죽게.
2. 45분마다 `/kaggle/working`에 체크포인트, 그리고 HF Hub로 올린다.
3. 세션이 시작되면 장비부터 확인한다(TPU라고 했는데 CPU 이미지가 뜨는 경우가 보고됨).
4. 계정은 하나만. 다중 계정은 약관 위반이다.

## 8.4 추론 지연 (물리 법칙 버전)

순차 디코딩은 계산이 아니라 **메모리 대역폭**에 묶인다.
$$\text{토큰당} \approx \frac{214.59\text{M} \times 2\ \text{바이트}}{230\ \text{GB/s}} \approx 1.87\ \text{ms}$$
- 탐욕 100토큰 (r=4): **약 0.19초**
- MCTS 평균 18시뮬, 배치 16: **약 0.9~1.25초**

(Gemini 1차안의 "0.0007초"는 T4가 빛의 속도로 도는 우주의 이야기였다. ⚡🐢)

## 8.5 엔지니어링 체크리스트
- T4: fp16 + fp32 누적, Triton 3.2.0 고정, 순수 PyTorch 청크 스캔 대비
- TPU: JAX 정적 shape, `associative_scan`, 컴파일 캐시
- 샌드박스 병목: 채점 호출을 묶어서 병렬 처리, 자주 쓰는 SymPy 검사는 캐시
- 파라미터 수는 **실제 모듈을 인스턴스화해서 세는 CI 검사**로 1억 넘으면 빌드 실패

# 10. 스케일링 & 북극성: 0.1B → 10B → ASI (신약·난제·코드)

## 10.1 이사 갈 때 들고 가는 것들 📦

헤파이스토스의 능력은 상당 부분 **가중치 밖**에 쌓인다. 그래서 몸(코어)을 키울 때 이삿짐이 공짜로 따라온다.

| 자산 | 어디에 있나 | 큰 코어로 옮길 때 |
|---|---|---|
| 스킬 라이브러리 (Stitch 매크로, Lean 보조정리, 파이썬 함수) | 파라미터 0, 파일 | **첫날 그대로 사용** |
| 검증 통과 궤적 수백만 개 | 데이터셋 | 큰 코어의 고밀도 사전학습 데이터 |
| 절차 생성기 + 채점기 레지스트리 | 코드 | 그대로 |
| 커리큘럼 상태 (난이도 다이얼, 영역 계단 위치) | 설정 | 그대로 |

이직할 때 포트폴리오 들고 가는 것처럼. 💼

### 깊이 → 폭 증류
1B 코어는 MCTS 한 단계가 T4에서 수십 초씩 걸릴 수 있다 [추정]. 그래서 **작은 코어 + MCTS가 만든 데이터로 큰 코어를 가르쳐서**, 큰 코어는 얕은 한 번의 패스(r=1)로 같은 추론을 하게 만든다.

## 10.2 컴퓨트 경로 (사람이 따 온다, AI가 아니라)

| 규모 | Chinchilla 학습량 (6N×20N) | 무료 할당량 기준 |
|---|---|---|
| 0.1B | 1.2×10¹⁸ FLOPs | TPU 몇 분~시간 ✅ |
| 1B | 1.2×10²⁰ FLOPs | TPU 약 3주 ✅ |
| 10B | 1.2×10²² FLOPs | 무료 할당량으로 **약 7년** ❌ |

[추정; compute.md의 6ND 계산]

그래서 10B는 **성과로 지원을 받아서** 간다.
1. **Google TPU Research Cloud:** 무료 TPU 할당. 단 VM과 저장소 비용은 들고, 프로젝트당 크기 보장은 없다. 결과를 공개해야 한다 [검증됨: https://sites.research.google/trc/faq/].
2. **연구 지원금:** Modal 학술 지원 등 [검증됨: https://gpuperhour.com/blog/free-cloud-gpus-and-credits].
3. **HF 저장소 지원:** 공개 가치가 있는 데이터셋과 가중치 [검증됨: https://huggingface.co/docs/hub/en/storage-limits].

**AI가 스스로 자원을 늘리는 건 금지.** 사람이 성과 논문을 들고 가서 따 오는 건 정공법이다. "0원으로 GPT-3.5 추론 격파 + 선생님 초월 증거" 논문 한 편이면 명분은 충분하다. 🏆

## 10.3 북극성: 항암 신약 🧬

### 시뮬레이터를 채점기로
| 도구 | 판정하는 것 | 주의 |
|---|---|---|
| RDKit | 원자가, 약물 유사성(리핀스키 5규칙), 합성 용이성 | 결정론적 |
| AutoDock Vina | 표적 단백질과의 결합 에너지 추정 | **근사 채점기.** 정답이 아니라 추정치 |
| OpenMM | 분자 동역학으로 결합 안정성 확인 | 비싸다 |

정직 메모: 이 영역 채점기는 바둑 규칙처럼 완벽하지 않다. 도킹 점수는 실제 약효와 다를 수 있다. 그리고 ESMFold 같은 신경망 예측기는 **파라미터 0도 아니고 정확하지도 않다.** 그래서 이 단계의 RSI는 "근사 채점기 + 사람 전문가 + 실제 실험"의 조합이 된다.

### 루프
1. 정책이 분자 변형(SMILES 편집, 역합성 절단)을 제안한다.
2. 물리 엔진이 에너지를 판정한다.
3. **기대 정보 이득**이 가장 큰 후보만 골라서 사람에게 실험을 제안한다. "어떤 실험을 해야 가장 많이 배우나"를 추론하는 것 자체가 북극성 단계의 핵심 능력이다.

### 반드시 같이 가는 것
이 단계에서는 안전장치가 선택이 아니라 생명줄이다. 같은 능력이 약도 만들고 독도 만들 수 있다. (→ 11장)

# 11. 능력 비례 안전장치: 빨리 달리려면 잘 서야 한다

F1 머신이 승용차보다 브레이크가 훨씬 좋은 이유는 **빨리 달리려고**다. 🏎️🛑 곡선이 로그면 안전장치가 거의 필요 없다(알아서 멈추니까). 그런데 우리가 원하는 건 지수 곡선이다. **성공할수록 위험도 같이 커진다.** 그래서 브레이크도 능력에 비례해서 업그레이드한다.

이 장은 농담을 줄인다. 내용은 단단해야 한다.

## 11.1 1일차부터

| 장치 | 내용 |
|---|---|
| **채점기 불가침** | 채점기, 보상 함수, 평가 세트는 읽기 전용 파일시스템. 부팅 때 SHA-256 확인. 모델은 읽지도 고치지도 못한다 |
| **격리** | 학습과 롤아웃 컨테이너는 네트워크 차단(`--network none`). seccomp로 소켓 호출, 허가 안 된 프로세스 실행, 샌드박스 밖 경로 접근 시 즉시 종료 |
| **감사 기록** | 세대마다 시드, 코드 커밋 해시, 채점기 해시, 손실 로그, MCTS 흔적 표본을 변조 불가 기록으로 남긴다. 추론 흔적은 **실행 가능한 프로그램**이라 사람이 검사할 수 있다 |
| **자원 상한** | 연산, 저장소, 네트워크 고정. 스스로 자원을 늘리는 행동 금지 |
| **킬 스위치** | H_g > 5점, 채점기 우회 시도, 예상 못 한 네트워크·파일 접근 중 하나라도 생기면 즉시 정지 |

### 왜 "생각을 코드로 남기는 천재"가 안전에 유리한가
GPT-6 Astra는 추론을 머릿속으로 하게 바꿨더니 **모니터링이 더 어려워졌다고** 시스템 카드에서 직접 인정했다 (로스트쇼에서 다룬 내용). 헤파이스토스의 추론 흔적은 파이썬 AST, SMT 단언, Lean 전술이다. **똑똑해질수록 감사도 같이 쉬워지게** 설계할 수 있다.

## 11.2 L4 이상
- 학습 파이프라인, 탐색 알고리즘, 손실 함수, 학습률, 데이터 생성기를 바꾸는 제안은 **사람이 읽을 수 있는 Git diff**로 올라오고, **사람이 승인해야** 다음 세대에 들어간다.
- L5(아키텍처 자기 재설계)는 **잠금.** 사람 관리 아래 연구 전용, 에어갭, 자동 실행 없음.

## 11.3 생물·화학 단계
| 장치 | 내용 |
|---|---|
| 기본 비활성 | 생물·화학 도구와 데이터는 기본적으로 꺼져 있다 |
| 외부 이중용도 검토 | 하나라도 켜려면 **외부** 전문가의 이중용도 검토를 통과해야 한다 |
| 차단 목록 | 학습된 필터가 아니라 **고정된 규칙 필터**로 화학무기, 생물독소, 대유행 가능 병원체 관련 질의와 구조를 거부한다 |
| 습식 실험 에어갭 | 모델은 로봇 실험 장비를 직접 구동하지 못한다. 실험실이 실행할 수 있는 모든 결과물은 **사람 전문가 검토** 필수 |

## 11.4 황금률

> **사람에게 해가 갈 가능성이 조금이라도 보이면, 즉시 그리고 무조건 멈춘다.**

이건 이 프로젝트를 시작할 때 사장님이 직접 건 조건이다. 꿈을 막는 장치가 아니라 **꿈이 터지지 않게 하는 장치**다. 스페이스X 로켓에도 비행 종료 시스템이 있어서 오히려 과감하게 쏠 수 있다. 🚀

## 12.2 실험 1: Game of 24에서 자기 개선 1세대 (코드 아님, 기획)

**1. 목적과 가설**
- 사람 시연 0개로 자기 개선 한 세대(g0 → g1)를 돌려서, 탐색 결과가 정책 가중치로 증류되는지 확인한다.
- 가설: 탐욕 pass@1이 홀드아웃에서 **+10%p 이상** 오르고, 랜덤 보상 대조군보다 **+8%p 이상** 높다.

**2. 영역과 데이터**
- Game of 24: 1~9 사이 정수 4개로 +, −, ×, ÷를 써서 정확히 24 만들기.
- 학습용: 절차 생성 400문제. 홀드아웃: Tree-of-Thoughts 논문의 표준 어려운 문제 100개 [검증됨: https://arxiv.org/pdf/2305.10601].
- 채점기: 파이썬 산수 평가기. 숫자 4개를 정확히 한 번씩 썼는지 + |값 − 24| < 10⁻⁶.

**3. 절차**
1. **Stage 0 부트로더로 학습된 코어**에서 시작한다. (학습 안 된 코어는 거의 0%를 풀어서 검증 통과 버퍼가 비어 버린다.) 홀드아웃 100문제 탐욕 pass@1 = S₀ 측정.
2. 학습용 400문제마다 MCTS 64시뮬레이션 (c_puct = 1.25, 디리클레 α = 0.3, ε = 0.25). 리프마다 채점기 호출. 방문 분포와 z ∈ {−1, +1}를 기록하고 성공 궤적만 버퍼에 넣는다.
3. 2× T4에서 버퍼로 3에폭 학습 (AdamW, 학습률 2×10⁻⁴, 가중치 감쇠 0.01, 배치 32, 코사인). 정책은 방문 분포, 가치는 z를 따라간다 → g1.
4. g1을 탐색 없이(r=1) 홀드아웃에서 평가 → S₁. Δ = S₁ − S₀.
5. 탐색 내재화 E₁ = (g0이 80% 도달에 필요한 시뮬 수) / (g1이 필요한 시뮬 수).

**4. 측정**
- 주 지표: 홀드아웃 탐욕 pass@1
- 기준: g0의 MCTS pass@1
- 엔지니어링 실측 (감사 추가): 가치 헤드가 샌드박스 전에 잘라 낸 가지 비율, 상태 캐시 vs 접두사 재계산 시 초당 노드 수, Kaggle vCPU 초당 채점 건수

**5. 대조군**
- 똑같이 학습하되 z를 동전 던지기(베르누이 0.5)로 바꾼 쌍둥이 g1_ctrl.

**6. 통과·킬 기준**

| 통과 | 킬 |
|---|---|
| Δ ≥ +10%p | Δ ≤ 0 |
| S₁ − S₁_ctrl ≥ +8%p | S₁ − S₁_ctrl < 3%p (채점기와 무관한 암기) |
| E₁ ≥ 1.5 | MCTS가 정책 사전확률보다 못함 |

**7. 연산과 시간**
- 롤아웃: 400 × 64 × 40토큰 ≈ 1.02×10⁶ 토큰, 2× T4로 약 8분
- 학습 약 2분, 평가 약 25초
- **합계 약 15~25분** (Stage 0 제외). 대조군까지 약 0.8 GPU시간.

`acc + 6.0` 같은 덧셈은 이 실험 어디에도 없다. 진짜로 돌려서 진짜로 잰다. 안 오르면 안 올랐다고 쓴다. 🥫
