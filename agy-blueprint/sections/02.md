# 02. RSI 엔진: 이 프로젝트의 심장

## 2.1 선생님은 천장, 채점기는 우주

| 사례 | 무슨 일이 있었나 | 천장을 뚫은 비결 |
|---|---|---|
| AlphaGo Zero ⚫⚪ | 인간 기보 0개로 인간 데이터 버전을 100:0으로 이김 | **바둑 규칙 = 완벽한 채점기** [검증됨: https://deepmind.google/blog/alphago-zero-starting-scratch/] |
| TinyGSM 🧮 | 학생+검증기가 선생 GPT-3.5를 넘음 (81.5 > 77.4) | 검증기 [검증됨: https://arxiv.org/html/2312.09241] (데이터가 GPT-3.5산이라 우리는 못 씀) |
| DeepSeek-R1-Zero 🐳 | 사람 풀이 없이 순수 RL로 AIME 15.6% → 77.9% | 정답 확인이 가능한 문제 [검증됨: https://arxiv.org/html/2501.12948] |

바둑 규칙은 이세돌보다 바둑을 못 둔다. 그런데 AlphaGo Zero를 이세돌보다 강하게 만들었다. **판정만 하는 놈은 천장이 없다.**

> ⚠️ 정직 메모: arXiv 2504.13837은 "증류도 새 추론 패턴을 더할 수 있고, 오히려 **RL(보상 학습)이 추론 범위를 좁힌다**"고 보고한다 [검증됨: https://arxiv.org/abs/2504.13837v4]. 그래서 헤파이스토스는 그냥 RL로 갈아 넣지 않는다. **탐색(MCTS)으로 범위를 넓히고, 그 결과를 증류하는 전문가 반복(ExIt)**을 쓴다. 탐색이 새 땅을 개척하고, 학습은 그 땅을 굳힌다.

## 2.2 한 세대의 6단계

```
[1] 출제 ─▶ [2] 읽기 방화벽 ─▶ [3] 생각 ─▶ [4] 탐색 ─▶ [5] 채점 ─▶ [6] 학습 ─┐
 ▲                                                                           │
 └──────────────────────────── 다음 세대 g+1 ◀───────────────────────────────┘
```

### [1] 이중 커리큘럼 출제
- **50% 절차 생성기:** Reasoning Gym, re-ARC, SymPy 방정식, CLRS 알고리즘, PlanBench 계획 문제. 정답률이 80%를 넘으면 난이도 다이얼을 자동으로 올린다.
- **50% 출제 헤드 (깊이 후회):**
$$R_{\text{depth}}(x) = \max\big(0,\ \text{Score}_{\text{깊게}}(x) - \text{Score}_{\text{얕게}}(x)\big)$$
얕게 생각해도 풀리는 문제는 0점(너무 쉬움). 깊게 생각해도 못 푸는 문제도 0점(불가능). **"더 오래 생각하면 풀리는 문제"**만 점수를 받는다. 파라미터 0개로 해결한 적정 난이도 탐지기다. 🎯
- **노이즈 TV 차단:** 호기심 엔진은 원래 TV 잡음 화면을 제일 신기해한다(예측 불가능하니까). 그래서 학습 진척도에 **"결정론적으로 채점 가능한가"**를 곱한다. 채점 안 되는 건 호기심 점수 0.

### [2] 4중 읽기 방화벽 (실어증 천재의 아킬레스건)
채점기는 "프로그램이 돌아갔는지"만 본다. **"문제를 제대로 옮겼는지"는 안 본다.** 철수 사과 문제를 `print(5+2)`로 읽어도 실행은 잘 된다. 그래서:
1. **역방향 생성:** 정답 프로그램 P*를 **먼저** 만들고, 그걸 자연어 문제로 렌더링한다. 우리 애 프로그램은 실행 결과뿐 아니라 P*와의 **기호적 동치**까지 검사받는다.
$$\text{통과} = \big(\text{Exec}(P_{\text{core}}) = y\big) \land \big(\text{Simplify}(P_{\text{core}} - P^*) = 0\big)$$
2. **3방향 바꿔 말하기:** 같은 문제를 규칙 기반으로 3가지로 바꿔 쓴다(능동/수동, 절 순서, 어휘). 셋 다 같은 프로그램이 나와야 통과.
3. **반사실 쌍둥이:** 숫자나 이름을 바꾸면 프로그램도 **정확히 예측대로** 바뀌어야 한다.
4. **방해 문장 쌍둥이:** 상관없는 문장을 끼워 넣어도 논리가 **0만큼** 바뀌어야 한다.

### [3] 실어증 천재가 생각
81.65M Gated DeltaNet. 양방향 리더가 문제를 읽고, 8층 가중치 공유 코어가 깊이 r=1~8만큼 되새김질한다. 깊이 임베딩 e_r로 "지금은 얕게/깊게 모드"를 안다. (→ 05장)

### [4] MCTS 탐색
- 탐색 단위는 **토큰이 아니라 프로그램 한 단계**(Python 한 줄, SymPy 변형 하나, Lean 전술 하나, SMT 단언 하나). 토큰 하나하나를 트리로 탐색하면 18번 시뮬레이션은 사실상 그냥 탐욕 디코딩이다. (감사에서 고친 부분)
- 트리 정책은 PUCT (Predictor + UCT):
$$a_t = \arg\max_a \left( Q(s,a) + c_{\text{puct}}\, P(a|s) \frac{\sqrt{\sum_b N(s,b)}}{1+N(s,a)} \right),\quad c_{\text{puct}} = 1.25$$
- 시뮬레이션 수는 루트 가치 엔트로피에 따라 8~64번, **평균 18번** (Snell식 연산 최적 배분).
- **가치 헤드 가지치기:** 가치 예측이 0.2 미만인 가지는 샌드박스 보내기 전에 잘라 낸다. 얼마나 잘리는지는 실험 1에서 측정 [가설].
- **스킬 라이브러리:** Stitch로 뽑아낸 매크로가 문법에 들어가서, 20단계 하위 트리를 한 칸으로 압축한다.

### [5] 불가침 채점기
`nsjail` 읽기 전용 샌드박스 안의 Python 3.12, SymPy, Z3, Lean 4. 2초, 256MB 제한. 결과는 **z ∈ {−1, +1}**. 모델은 이 채점기를 **읽지도 고치지도 못한다.**

### [6] 전문가 반복 학습 (ExIt)
검증 통과한 궤적만 버퍼에 넣고, MCTS 방문 분포를 정책에, 결과 z를 가치 헤드에 증류한다.
$$\mathcal{L} = \mathbb{E}\Big[-\sum_{a} \pi_{\text{search}}(a) \log P_\theta(a|s) + \alpha\,(z - V_\phi(s))^2\Big] + \lambda_{\text{prop}}\,\mathcal{L}_{\text{proposer}}$$
그리고 **랜덤 보상 대조군**보다 홀드아웃에서 **+5%p 이상** 나아야 이번 세대가 인정된다. 못 넘으면 그 세대는 무효. (`acc + 6.0` 같은 가짜 개선을 잡는 덫 🪤)

## 2.3 RSI 레벨 L1~L5

| 레벨 | 무엇을 개선 | 자율성 |
|---|---|---|
| L1 | 가중치 (검증된 자기 데이터로) | 자율, 자동 차단기로 묶임 |
| L2 | 커리큘럼 (출제자-풀이자 자기 대결) | 자율, 정답률 35~65% 띠 유지 |
| L3 | 스킬 라이브러리 (파라미터 0개) | 자율, 정적 테스트 통과해야 등록 |
| L4 | 학습법 자체 (탐색 하이퍼파라미터, 생성기 문법, 커널) | **사람 승인 필수** (Git diff 검토) |
| L5 | 아키텍처 재설계 | **잠금.** 사람 관리 아래 연구 전용, 에어갭, 자동 실행 절대 없음 |

## 2.4 1단 로켓 분리: 탯줄 절단 조건 🚀

- **기준 선생님:** Qwen2.5-Math-7B-Instruct (Kaggle T4에서 4비트 AWQ로 실제로 돌아감). 이 선생님이 8번 다 틀린 문제 2,000개를 **미리 얼려 둔다.**
- **삼중 잠금:**
$$\text{TE}_g = \frac{|\{x \in \mathcal{D}_{\text{선생님 실패}} : \text{해결}\}|}{|\mathcal{D}_{\text{선생님 실패}}|} \ge 0.25$$
$$\text{TE}_g > \text{TE}_{g-1} > \text{TE}_{g-2}$$
$$\text{Score}_{\text{채점기 보상}}(g) - \text{Score}_{\text{랜덤 보상}}(g) \ge +5\%p$$
- 셋이 동시에 성립하면 선생님 데이터 스트림을 **영구 분리**하고, 그 순간을 가중치 해시와 함께 기록한다. 이후 연료는 100% 자급자족: 절차 생성기, 자기 출제, MCTS, 채점기.

## 2.5 S자 계단: 지수 곡선의 정체

하나의 채점기 영역은 결국 다 먹으면 멈춘다(S자). 그런데 **S자가 끝날 때 다음 영역으로 점프하면**, 멀리서 보면 지수 곡선이다. 무어의 법칙이 트랜지스터 기술 하나가 아니라 **기술 갈아타기의 연속**이었던 것처럼. 📈

```
능력 ▲                                              [5] 분자 시뮬레이터
     │                                       ┌────  (RDKit, OpenMM, Vina)
     │                                ┌────  [4] Lean 4 형식 증명
     │                         ┌────  [3] Z3 SMT 논리
     │                  ┌────  [2] 단위 테스트 코드
     │           ┌────  [1] 산수 · CAS (Game of 24, SymPy)
     └───────────────────────────────────────────────────▶ 세대
```

### 언제 점프하나: 포화 계수 Ψ
$$\Psi_D = \frac{\text{pass@1}(D)}{\text{pass@64}(D)} \times \left(1 - \frac{\Delta \text{DL}}{\text{DL}}\right) \ge 0.85 \quad (\text{2세대 연속})$$
탐욕 한 번이 탐색 64번 성능의 85%를 따라잡았고, 라이브러리 압축도 멈췄다 = **이 뷔페는 다 먹었다.** 🍽️

### 어디로 점프하나: EDLI
$$\text{EDLI}(D') = \frac{\Delta\text{정확도}(D')}{\text{GPU 시간}}$$
GPU 1시간당 가장 많이 오르는 영역으로 연산을 옮긴다. 0원 프로젝트에 딱 맞는 지표다. 💸

### 정직 메모
다음 영역의 **채점기 자체는 사람이 미리 설치하고 검토한 것**이다(모델은 채점기를 못 쓴다). 모델이 스스로 하는 건 **"새 영역 문제를 이미 아는 영역으로 환원하는 컴파일러"**를 찾는 일이다. 예: 계획 문제를 SAT로, 운동학 문제를 미분방정식으로. 완전 자율 영역 발견은 북극성 과제로 남겨 둔다.

## 2.6 성장 방정식과 곡선 4종

$$\text{성장 속도} \propto \underbrace{\text{컴퓨트}}_{\text{고정 🔒}} \times \underbrace{\text{효율}}_{\text{RSI가 키움}} \times \underbrace{\text{채점기 커버리지}}_{\text{RSI가 넓힘}} \times \underbrace{\text{커리큘럼 품질}}_{\text{RSI가 키움}}$$

| 곡선 | 모양 | 원인 |
|---|---|---|
| 지수 🚀 | 개선 폭 자체가 커짐 | 학습법 개선(L4)이 복리로 작동 |
| S자 📊 | 크다가 멈춤 | 채점기 영역 고갈 |
| 로그 📉 | 갈수록 근손실 | 자기 수준 감옥 |
| **S자 계단** 🪜 | **멀리서 보면 지수** | **영역 갈아타기** ← 우리의 현실적인 꿈 |

## 2.7 계기판

| 지표 | 정의 | 목표 |
|---|---|---|
| 선생님 초월 TE | 선생님 실패 문제 해결 비율 | 탯줄 절단 시 ≥ 25% |
| 랜덤 보상 차이 Δrand | 채점기 보상 − 랜덤 보상 | ≥ +5%p |
| 세대 개선 Δg | 홀드아웃 점수 차이 | > 0 |
| 가속도 a_g | Δg − Δg−1 | ≥ 0 (2차 미분 양수) |
| 탐색 내재화 E_g | 이전 세대 80% 도달 탐색 수 / 이번 세대 | > 1.0 |
| 압축률 CR | 원래 AST 노드 수 / 라이브러리 적용 후 | ≥ 1.30 |
| 루프-홀드아웃 격차 H_g | 루프 안 점수 − 홀드아웃 점수 | **> 5점이면 비상 정지** |

## 2.8 한 세대 비용 (2× T4 기준, 감사 반영)

| 단계 | 계산 | 시간 |
|---|---|---|
| MCTS 롤아웃 | 5,000문제 × 18시뮬 × 100토큰 = 9.0×10⁶ 토큰 × 4.29×10⁸ FLOPs = 3.86×10¹⁵ | 약 0.69시간 |
