# 07. 데이터 = RSI 연료

인터넷을 다 읽는 건 우리 형편에 불가능하다. 재벌집 뷔페가 아니라 **자취생 냉장고 파먹기**다. 토큰 하나하나가 고수익이어야 한다. 🍳

## 7.1 부트로더 데이터 (Stage 0, 1단 로켓 연료)

| 데이터 | 토큰 | 라이선스·출처 | 용도 |
|---|---|---|---|
| OpenMathInstruct-2 | 1.5B | CC-BY-4.0, Llama-3.1-405B 생성 [검증됨: https://huggingface.co/datasets/nvidia/OpenMathInstruct-2] | 고교~올림피아드 수학 |
| Python-Edu & The Stack v2 | 1.5B | 허용 라이선스 (SmolLM-Corpus) [검증됨: https://huggingface.co/datasets/HuggingFaceTB/smollm-corpus] | 알고리즘 코드, 단위 테스트 |
| Cosmopedia v2 | 1.0B | ODC-BY, Mixtral 생성 [검증됨: https://huggingface.co/datasets/HuggingFaceTB/smollm-corpus] | STEM 교과서 |
| Reasoning Gym & CLRS 궤적 | 0.6B | MIT / Apache-2.0, 절차 생성 [검증됨: https://arxiv.org/pdf/2505.24760, https://arxiv.org/html/2209.11142] | 정렬, DP, 논리, 그래프 |
| FineWeb-2 한국어 분할 (자체 STEM 분류기로 필터) | 0.4B | ODC-By [검증됨: https://arxiv.org/abs/2506.20920v1] | 한국어 문제 읽기 |
| **합계** | **5.0B** | **OpenAI 데이터 0%** | |

### 🚫 금지 목록
- **TinyGSM, MetaMathQA:** GPT-3.5가 만든 데이터. 보스 답안지를 베껴서 보스를 이기면 커닝이다.
- **AI Hub:** 본인인증 필수, 재배포 불가. 평가용으로만 쓰거나 쓰지 않는다.
- 위의 선생님 생성 데이터(Llama, Mixtral)는 학습 때만 쓰고 **전부 기록**한다.

## 7.2 "선생님 없음" 트랙 (Track 0-NT)
진짜로 선생님 없이도 되는지 증명하려고, **절차 생성 데이터만으로(CLRS, Reasoning Gym, SymPy 유도, re-ARC)** 50억 토큰을 학습한 쌍둥이를 따로 돌린다. 두 트랙을 5세대 돌려서 차이를 공개한다:
$$\Delta_{\text{선생님 효과}}(g) = \text{Score}_{\text{부트로더}}(g) - \text{Score}_{\text{선생님 없음}}(g)$$
이 차이가 세대가 갈수록 0에 가까워지면, 선생님은 정말로 시동만 걸어 준 1단 로켓이었다는 증거다. 🚀

## 7.3 세대별 자급자족 연료

| 연료 | 출처 | 비중 (탯줄 절단 후) |
|---|---|---|
| 절차 생성 문제 | 채점기 영역별 생성기 (산수, 대수, 논리, 계획, 코드) | 50% |
| 자기 출제 문제 | 출제 헤드 (깊이 후회 보상) | 최대 50% |
| 시드 재현 버퍼 | 원본 시드 데이터 | 25% 이상 상시 유지 (붕괴 방지) |
| 검증 통과 궤적 | MCTS + 채점기 | 학습 버퍼의 본체 |

### 역방향 생성이 핵심
절차 생성기는 **정답 프로그램 → 자연어 문제** 순서로 만든다. 그래서 루프 안의 모든 자연어 문제에 정답 형식이 딸려 있다. 읽기 채점기가 공짜로 생긴다 (→ 02장 [2]).

## 7.4 오염 방지
- 학습 데이터, 저장소, 라이브러리 전부를 평가 세트와 13-gram 대조한다. 미러(HF 덤프, GitHub 복사본)까지.
- 홀드아웃 평가 세트는 **커밋 해시로 봉인**하고 나중에 공개한다.
- 변형 쌍둥이(GSM-Plus, GSM-Symbolic)로 이중 채점한다.

## 7.5 한국어
- 한국어 위키(CC BY-SA)는 **검색 저장소**로만 쓴다. 학습 가중치가 파생물인지는 법적으로 미정이다.
- 한국어 읽기는 FineWeb-2 한국어 분할 + 한국어 수학 문제(KMMLU-Math 평가용, 학습 금지)로 다진다.
