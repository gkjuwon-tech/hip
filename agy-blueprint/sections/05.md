## 5.3 왜 트랜스포머가 아닌가: Gated DeltaNet 재귀

어텐션은 새 토큰마다 지난 토큰 전부와 눈을 맞추고(O(n²)), KV 캐시가 계속 불어난다. Gated DeltaNet은 **고정 크기 기억 행렬**을 델타 규칙으로 덮어쓴다 [검증됨: https://arxiv.org/abs/2412.06464v3]:

$$S_t = \alpha_t\, S_{t-1}\left(I - \beta_t\, k_t k_t^{\top}\right) + \beta_t\, v_t k_t^{\top}, \qquad y_t = S_t\, q_t$$

- α_t: 지우기 게이트 (얼마나 잊을지)
- β_t: 쓰기 강도 (얼마나 세게 새로 적을지)
- 상태 S_t는 헤드 5개 × 128×128 = 81,920개 값, fp16으로 **층당 약 160KB**. 문장이 아무리 길어도 크기가 안 변한다.

### MCTS에 왜 유리한가
트리 노드마다 상태를 통째로 저장할 수 있다. 노드 256개 × 8층 × 160KB ≈ **320MB**, 접두사 길이와 무관. 트랜스포머는 노드마다 KV 캐시가 토큰 수만큼 커진다. 실제로 얼마나 빨라지는지는 **아직 안 쟀다** [가설] → 실험 1에서 측정.

### 정직 메모: 어텐션 없는 대가
어텐션 없는 TRM-MLP는 ARC-AGI-1에서 44.6% → 29.6%, 미로에서 85.3% → 0.0%로 떨어졌다 [검증됨: https://arxiv.org/html/2510.04871v1]. "문맥에서 정확히 원하는 걸 꺼내는 능력"이 약하다는 뜻이다. 그래서 헤파이스토스는 (1) 델타 규칙의 정확한 덮어쓰기, (2) ARC용 2D 격자 어댑터와 문제별 테스트 시점 학습, (3) DROP용 포인터 헤드로 보완한다. 그래도 ARC 목표는 [가설] 등급이다.

## 5.4 모듈 상세

### 양방향 리더 (22.16M)
- 정방향 2블록 + 역방향 2블록. 문제 전체를 양쪽에서 읽는다(생성이 아니라 이해라서 가능).
- ELECTRA식 대체 토큰 탐지 사전학습으로 읽기 능력을 키운다 [검증됨: https://arxiv.org/abs/2003.10555].

### 재귀 코어 (44.31M)
- 8개 블록을 **r번 반복**. 깊이 임베딩 e_r로 "지금 몇 번째 되새김질인지" 안다.
- 학습 때 r을 무작위로 뽑아서, 추론 때 얕게(r=1~2, 빠른 걸러내기)와 깊게(r=8, 어려운 문제)를 같은 가중치로 다 한다.

### 정책 헤드 / 출제 헤드 (각 1.31M)
- 형식 어휘 2,048개 위의 분포. 정책은 다음 프로그램 단계를, 출제자는 새 문제 명세를 낸다.
- 출제자도 **형식 명세**를 낸다(예: "4개 수, 목표 24, 난이도 3"). 자연어 문제는 규칙 기반 렌더러가 만든다. 실어증 천재는 출제할 때도 말을 안 한다. 🤐

### 가치 헤드 (0.17M)
- 현재 상태에서 성공 확률 예측. MCTS 평가와 가지치기에 쓴다.
- 학습 신호는 **채점기의 z뿐**이다. 자기 선호로 자기를 채점하지 않는다.

### DROP 포인터 (0.41M)
- 지문에서 숫자나 구간의 시작/끝 위치를 가리킨다. 말을 만들지 않고 **복사**한다.

### 검색 키 투영 (0.17M)
- Tier B(GPQA, MedQA, StrategyQA)용. BM25(파라미터 0) 결과를 코어 표현과 맞춘다.
