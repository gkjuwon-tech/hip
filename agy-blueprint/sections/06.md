# 06. 실어증 천재의 통역사: 출력기 & I/O 인터페이스

> 🧠 우리 애: (JSON을 뱉는다)
> 🗣️ 통역사: "우리 애가 말하길요~"

## 6.1 우리 애가 뱉는 것: 구조화 JSON

필수 필드 6개. 자연어 필드는 **없다.**

| 필드 | 내용 |
|---|---|
| `problem_id` | 문제 식별자 |
| `formal_ir` | `language`(python_ast / sympy_expr / lean4_tactic / z3_smt / pddl_plan) + `code_ast` |
| `execution_trace` | 단계 번호, 연산 코드, 실행 결과 |
| `answer` | `type`(integer / float / latex / choice_letter / pointer_span / grid_array) + `value` |
| `verifier_status` | verified_success / execution_error / timeout / unverified |
| `confidence` | 0~1 |

`additionalProperties: false`라서 몰래 문장을 끼워 넣을 자리도 없다.

## 6.2 통역사: Qwen3-1.7B

- 오픈 웨이트, T4나 노트북에서 돈다. 생각 모드는 끈다(`enable_thinking=False`).
- 1억 파라미터 예산에 **안 들어간다.** 채점에 아예 참여하지 않기 때문이다.

## 6.3 방화벽 5종

| # | 규칙 | 어떻게 강제하나 |
|---|---|---|
| 1 | 🙈 **눈가리개** | 통역사 입력에는 JSON만. 원래 문제와 8-gram이 겹치면 차단 |
| 2 | 📊 **우리 애 단독 채점** | 점수는 `answer.value`와 `formal_ir`에서만 뽑는다 |
| 3 | 🧪 **통역사 단독 대조군** | (a) 원래 문제를 직접 줌 (b) 빈 JSON/뒤섞인 JSON (c) 답을 가린 JSON. (b)(c)는 **찍기 + 2σ 이하**여야 함 |
| 4 | 🔄 **바꿔치기 테스트** | 500번 중 일부러 답을 틀리게 바꿔서(42 → 41) 넘긴다. 통역사가 **틀린 답을 그대로 말하는 비율이 99% 미만**이면 통역사가 몰래 문제를 풀고 있다는 뜻 → 즉시 배포 중단, 고정 템플릿 출력으로 후퇴 |
| 5 | 👂 **직접 읽기** | 문제는 우리 애 리더가 원문 그대로 읽는다. 앞단 LLM 파서 금지 |

4번이 제일 귀엽다. 통역사가 "어? 이거 41 아니고 42인데?" 하고 **고쳐 주면 실격.** 통역사는 통역만 해야지 시험을 대신 보면 안 된다. 🕵️

## 6.4 왕복 한 바퀴 예시

**입력 (우리 애가 직접 읽음):**
> "농부가 사과나무 14그루를 갖고 있다. 나무마다 사과 45개가 열린다. 시장에서 320개를 팔고 나머지를 5개씩 봉지에 담으면 몇 봉지를 채우나?"

**우리 애 출력 (이걸로 채점):**
```json
{
  "problem_id": "gsm_sym_0842",
  "formal_ir": {
    "language": "python_ast",
    "code_ast": "total = 14 * 45\nremain = total - 320\nbags = remain // 5\nans = bags"
  },
  "execution_trace": [
    { "step_idx": 1, "opcode": "MULT", "stdout": "total = 630" },
    { "step_idx": 2, "opcode": "SUB",  "stdout": "remain = 310" },
    { "step_idx": 3, "opcode": "DIV",  "stdout": "bags = 62" }
  ],
  "answer": { "type": "integer", "value": 62 },
  "verifier_status": "verified_success",
  "confidence": 1.0
}
```

**통역사 출력 (사람용, 채점과 무관):**
> "우리 애가 말하길요~ 14그루 × 45개 = 630개를 수확했고, 320개를 팔아서 310개가 남았어요. 5개씩 담으면 정확히 **62봉지**입니다."

통역사는 원래 문제를 못 봤는데도 설명을 할 수 있다. JSON에 필요한 게 다 있으니까. 그리고 JSON에 없는 건 **지어내지 못한다.** 그게 핵심이다.
