# 04. 제1원리: 왜 선생님은 천장이고 채점기는 천장이 없나 + 왜 입과 뇌를 분리하나

## 4.1 거대 모델은 파라미터를 어디에 쓰나

| 용도 | 비용 | 헤파이스토스의 처리 |
|---|---|---|
| 사실 저장 | 파라미터당 약 2비트 [검증됨: https://arxiv.org/html/2404.05405] → 1억이면 약 25MB | **외부로 뺌**: BM25 저장소, 도구 |
| 유창한 말 | 큰 어휘 임베딩 + 생성 능력 | **통역사에게 외주** |
| 계산 흉내 | 자릿수 올림, 변수 추적을 가중치로 흉내 | **Python·SymPy·Z3에 맡김** (파라미터 0) |
| 추론 절차 | 읽기, 분해, 탐색, 검증 | **여기에 100% 몰빵** |

꼬마 모델이 TriviaQA 4.1%를 찍는 건 머리가 나빠서가 아니라 **뇌 용량이 USB 하나도 안 돼서**다 [검증됨: https://huggingface.co/HuggingFaceTB/SmolLM2-135M]. 그래서 지식은 산수적으로 밖으로 빼야 한다. 🧮

## 4.2 선생님은 왜 천장인가 (그리고 어디까지 맞는 말인가)

- **흉내 학습:** 학생은 선생님의 답안 분포를 따라간다. 선생님이 못 푸는 문제는 답안지에 없다. 복사기는 원본보다 선명해지지 않는다. 🖨️
- **정직하게 덧붙이면:** 이게 수학적으로 절대 법칙은 아니다 [가설]. arXiv 2504.13837은 증류가 새 패턴을 더할 수 있고, 반대로 **RL만 돌리면 pass@k가 큰 구간에서 기본 모델보다 범위가 좁아진다**고 보고한다 [검증됨: https://arxiv.org/abs/2504.13837v4].
- **그래서 우리 결론:** 천장을 뚫는 건 "선생님을 버리는 것"이 아니라 **"선생님이 줄 수 없는 신호를 쓰는 것"**이다. 그 신호가 채점기고, 그 신호로 새 땅을 찾는 도구가 탐색(MCTS)이다.

## 4.3 채점기는 왜 천장이 없나

채점기는 답을 **생성**하지 않고 **판정**만 한다. 판정은 생성보다 훨씬 쉽다. 스도쿠 답이 맞는지 확인하는 건 1초, 푸는 건 1시간이다. 그래서 **판정은 정확한데 생성은 서툰** 조합에서, 탐색으로 생성하고 판정으로 걸러서 학습하면, 학생은 판정자가 허락하는 한 어디까지든 간다.

```
선생님:  "이렇게 풀어"     → 선생님 수준까지만 끌어올림 🥫
채점기:  "맞음 / 틀림"     → 탐색만 충분하면 어디까지든 🚀
```

## 4.4 추론이란 무엇인가 (계산 관점)

추론 = **상태 공간에서 목표까지 가는 경로 찾기**다.
- 수학: 식 → 변형 → 증명 완료
- 코드: 명세 → 프로그램 → 테스트 통과
- 계획: 초기 상태 → 행동 순서 → 목표 상태
- 신약: 후보 분자 → 변형 → 결합 에너지 개선

전부 **형식 객체를 단계적으로 바꾸고, 각 단계를 검증하는 일**이다. 자연어는 이 과정의 입출력 포장지일 뿐이다. 그래서 우리 애는 포장지 공장(언어 생성)을 짓지 않는다.

## 4.5 왜 입과 뇌를 분리할 수 있나: 이해는 생성보다 싸다

- 문장을 **읽고 판단**하는 일(분류, 함의 판단, 빈칸 위치 찾기)은 작은 판별형 인코더도 꽤 잘한다 [추정; io_split.md 리서치 노트 참고].
- 문장을 **유창하게 지어내는** 일은 어휘 분포 전체를 정확히 모델링해야 해서 비싸다.
- 우리 애의 출력은 어휘 2,048개짜리 **형식 언어**(파이썬 AST, SymPy 식, Lean 전술, SMT 단언)다. 16,384 토큰 입력 어휘로 **읽고**, 2,048 토큰 형식 어휘로 **쓴다.** 수만 개 자연어 어휘를 생성할 필요가 없다.

## 4.6 그래서 1억을 어디에 쓰나

| 쓰는 곳 | 파라미터 | 비율 |
|---|---|---|
| 재귀 추론 코어 (8층 × r번 반복) | 44.31M | 54% |
| 양방향 입력 리더 | 22.16M | 27% |
| 입력/형식 임베딩 | 11.80M | 14% |
| 정책·가치·출제·포인터·검색 헤드 | 3.37M | 4% |
| 기타 (깊이 임베딩, 격자 어댑터) | 0.01M | 0% |

**말하기에 쓰는 파라미터: 0.** 🤐 대신 같은 코어를 r번 되새김질해서, 실행 시 유효 파라미터는 r=4에서 214.59M, r=8에서 약 392M까지 늘어난다. 파라미터는 고정, **생각의 깊이는 시간으로 산다.**
