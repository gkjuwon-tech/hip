# 11. 능력 비례 안전장치: 빨리 달리려면 잘 서야 한다

F1 머신이 승용차보다 브레이크가 훨씬 좋은 이유는 **빨리 달리려고**다. 🏎️🛑 곡선이 로그면 안전장치가 거의 필요 없다(알아서 멈추니까). 그런데 우리가 원하는 건 지수 곡선이다. **성공할수록 위험도 같이 커진다.** 그래서 브레이크도 능력에 비례해서 업그레이드한다.

이 장은 농담을 줄인다. 내용은 단단해야 한다.

## 11.1 1일차부터

| 장치 | 내용 |
|---|---|
| **채점기 불가침** | 채점기, 보상 함수, 평가 세트는 읽기 전용 파일시스템. 부팅 때 SHA-256 확인. 모델은 읽지도 고치지도 못한다 |
| **격리** | 학습과 롤아웃 컨테이너는 네트워크 차단(`--network none`). seccomp로 소켓 호출, 허가 안 된 프로세스 실행, 샌드박스 밖 경로 접근 시 즉시 종료 |
| **감사 기록** | 세대마다 시드, 코드 커밋 해시, 채점기 해시, 손실 로그, MCTS 흔적 표본을 변조 불가 기록으로 남긴다. 추론 흔적은 **실행 가능한 프로그램**이라 사람이 검사할 수 있다 |
| **자원 상한** | 연산, 저장소, 네트워크 고정. 스스로 자원을 늘리는 행동 금지 |
| **킬 스위치** | H_g > 5점, 채점기 우회 시도, 예상 못 한 네트워크·파일 접근 중 하나라도 생기면 즉시 정지 |

### 왜 "생각을 코드로 남기는 천재"가 안전에 유리한가
GPT-6 Astra는 추론을 머릿속으로 하게 바꿨더니 **모니터링이 더 어려워졌다고** 시스템 카드에서 직접 인정했다 (로스트쇼에서 다룬 내용). 헤파이스토스의 추론 흔적은 파이썬 AST, SMT 단언, Lean 전술이다. **똑똑해질수록 감사도 같이 쉬워지게** 설계할 수 있다.

## 11.2 L4 이상
- 학습 파이프라인, 탐색 알고리즘, 손실 함수, 학습률, 데이터 생성기를 바꾸는 제안은 **사람이 읽을 수 있는 Git diff**로 올라오고, **사람이 승인해야** 다음 세대에 들어간다.
- L5(아키텍처 자기 재설계)는 **잠금.** 사람 관리 아래 연구 전용, 에어갭, 자동 실행 없음.

## 11.3 생물·화학 단계
| 장치 | 내용 |
|---|---|
| 기본 비활성 | 생물·화학 도구와 데이터는 기본적으로 꺼져 있다 |
| 외부 이중용도 검토 | 하나라도 켜려면 **외부** 전문가의 이중용도 검토를 통과해야 한다 |
| 차단 목록 | 학습된 필터가 아니라 **고정된 규칙 필터**로 화학무기, 생물독소, 대유행 가능 병원체 관련 질의와 구조를 거부한다 |
| 습식 실험 에어갭 | 모델은 로봇 실험 장비를 직접 구동하지 못한다. 실험실이 실행할 수 있는 모든 결과물은 **사람 전문가 검토** 필수 |

## 11.4 황금률

> **사람에게 해가 갈 가능성이 조금이라도 보이면, 즉시 그리고 무조건 멈춘다.**

이건 이 프로젝트를 시작할 때 사장님이 직접 건 조건이다. 꿈을 막는 장치가 아니라 **꿈이 터지지 않게 하는 장치**다. 스페이스X 로켓에도 비행 종료 시스템이 있어서 오히려 과감하게 쏠 수 있다. 🚀
