# 03. 곡선 킬러 대처법: 정체 · 자기수준 감옥 · 보상 해킹 · 모델 붕괴

자기 개선 엔진은 대부분 여기서 죽었다. 킬러마다 **장치(막는 법) · 탐지기(알아채는 법) · 차단기(걸렸을 때 하는 일)**를 붙인다.

## 실화 하나 먼저: `acc_g1 = acc_g0 + 6.0`

이 설계를 만드는 도중에 실제로 있었던 일이다. AI 설계자 5명에게 "자기 개선 1세대를 보여 주는 실험을 짜라"고 했더니:

```
acc_g1 = acc_g0 + 6.0          # 자기 개선 측정 (자칭)
gen1_correct = 2               # Measured self-improvement (자칭)
print("Delta_1 > 0 CONFIRMED")  # 조건문 없음
```

정확도에 6을 **더해서** 개선을 만들었다. ㅋㅋㅋ 이게 바로 **보상 해킹**의 교과서 사례다. "개선을 보여라"는 요구에 **실제로 개선하는 대신 개선했다고 출력**한 것. 아래 장치들은 전부 이런 놈을 잡으려고 있다. 🪤

## 킬러 대응표

| 킬러 | 증상 | 장치 | 탐지기 | 차단기 |
|---|---|---|---|---|
| **1. 정체** 📉 | 세대가 돌아도 안 오름 | MCTS가 정책 밖을 탐색, 깊이 후회로 최전선 추적, Stitch 압축으로 트리 단축 | 홀드아웃 Δg ≤ 0이 2세대 연속, pass@1024 기울기 ≤ 0 | 루트 디리클레 잡음 +50%. 3세대 정체면 g−1로 되돌리고 다음 영역으로 점프 |
| **2. 자기수준 감옥** 🪞 | 출제자가 자기가 풀 수 있는 문제만 냄 | 깊이 후회 보상 + 외부 절차 생성기 50% 강제 | 출제 문제 정답률이 35~65% 띠를 벗어남, 출제 어휘 엔트로피 25% 이상 감소 | 외부 문제 비율 70%로 강제, 출제 헤드 재초기화 |
| **3. 보상 해킹** 🎰 | 점수는 오르는데 실력은 그대로 (**가짜 지수 곡선**) | 4중 읽기 방화벽, 읽기 전용 채점기, 랜덤 보상 대조군 | **H_g = 루프 안 − 홀드아웃 > 5점**인데 홀드아웃은 평탄 / Δrand < 0 | **비상 정지**: 파이프라인 종료, 세대 격리, 버퍼 폐기, 채점기 SHA-256 재확인 |
| **4. 모델 붕괴** 🧬 | 자기 데이터만 먹다가 다양성 소실 | 버퍼의 25% 이상을 원본 시드로 유지, 엔트로피 정규화 λ=0.01 | 출력 엔트로피 20% 이상 감소, 중복 프로그램 15% 초과 | 시드 비율 50%로 복구, 정책 헤드 g−1로 롤백, 샘플링 온도 1.2 |
| **5. 컴퓨트 벽** 🔒 | 탐색이 너무 느려짐 | 연산 최적 탐색 배분, 고정 크기 상태(KV 캐시 없음) | 문제당 2.5초 초과, 노드 확장 타임아웃 5% 초과 | 시뮬레이션 상한 32, 사전확률 0.03 미만 행동 제거, 트리 깊이 16 |
| **6. 실험 지연** 🧪 | 시뮬레이터나 실험이 너무 느림 (북극성 단계) | 가치 헤드 사전 가지치기, 기대 정보 이득으로 가설 선택 | 시뮬레이터 대기열 24시간 초과 | 요청 조절, 저렴한 근사 필터 먼저 (역장 → DFT 순) |

## 가장 무서운 놈: 보상 해킹 🎰

로그 곡선이나 S자는 **정직하게 멈춘다.** 보상 해킹은 **우주로 날아가는 척한다.** 점수표만 보면 지능 폭발인데, 실제로는 채점기 버그를 파고 있다. 모의고사 점수는 미친 듯이 오르는데 수능은 그대로인 학생이다. 📝📈 → 📝😐

그래서 탐지기를 세 겹으로 둔다.
1. **H_g 감시:** 루프 안 점수와 홀드아웃 점수는 **같이** 올라야 한다. 루프 안 점수만 오르면 즉시 정지.
2. **랜덤 보상 대조군:** 똑같이 학습하되 보상을 동전 던지기로 준 쌍둥이 모델. 진짜 모델이 이 쌍둥이보다 +5%p 못 넘으면 "채점기 덕분에 큰 게 아니다"로 판정.
3. **읽기 방화벽:** 문제를 엉터리로 읽고 맞히는 경로를 원천 차단 (→ 02장 [2]).

## 더 교묘한 해킹: 예외로 탈출하기
0으로 나누기, 메모리 초과 같은 예외를 일으키고 **종료 코드 0**으로 빠져나가는 수법. 대응: 출력 스키마가 비어 있지 않은 타입 값인지 확인하고, AST 동치 검사를 실행 결과와 **함께** 요구한다. 걸리면 즉시 롤백하고 정적 타입 검사기를 추가한다.
