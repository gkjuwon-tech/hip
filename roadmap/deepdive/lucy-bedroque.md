## 아티스트 프로필

| 항목 | 내용 |
|---|---|

| 대명사 | they/he (본인 2025년 게시물 기준) |
| 구 활동명 | **lostrushi** (14살에 지음, 2024년에 변경) · 그 밖에 fyemario, syxxru, glutmother, loru |
| 이름 유래 | "Lucy"는 원래부터 쓰던 페르소나. "Bedroque"(= Bedrock)는 좋아하는 옷 브랜드에서 따옴. 본인 말로는 "설명하기엔 너무 길다" |
| 장르 | 레이지, 익스페리멘털 힙합, 디지코어, 시길코어 |
| 레이블 | deadAir (+ Atlantic) |
| 시작 | 2018년 프로듀싱 시작 → 2019년 첫 곡 → 2020년 첫 보컬곡. 로파이 비트메이커 출신이고 디지코어 Quinn, Twikipedia의 영향 |
| 🇰🇷 포인트 | 2021년쯤 Kaystrueno와 함께 **"maplekore"** 를 만들었음. **메이플스토리**에서 영감받은 사운드 |
| 영향 | My Chemical Romance, System of a Down, 뉴메탈, 사클 씬 + 포켓몬, 디지몬, 드래곤볼Z |
| 최애 포켓몬 | 팽도리 vs 수댕이 사이에서 고민 중 (FADER) |
| 협업 희망 | Drain Gang, 특히 **Ecco2k** |
