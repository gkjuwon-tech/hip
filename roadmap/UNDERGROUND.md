1. **레이블 카탈로그를 통째로 훑기:** Opium, deadAir, Surf Gang, XV/Lizzy Records, 10k Projects. 레이블 하나가 곧 씬 하나예요.
2. **프로듀서 크레딧 따라가기:** Wraith9 (UK UG), Evilgiane (저크), prettifun / skai / Ginseng / Legion (레이지 2세대). 좋은 곡이 있으면 래퍼보다 프로듀서를 먼저 검색.
3. **피처링 체인 타기:** *Unmusique* → prettifun → slayr *BloodLuxe* → Lucy Bedroque *c* → Jackzebra … 이렇게 피처링 목록을 따라가면 끝이 없어요.
4. **장르 차트 보기:** AOTY와 RYM의 **rage / plugg / pluggnb / jerk** 장르 차트를 연도별로. 단, **평가 인원 수를 같이 볼 것.** 18명 평가 83점과 6,000명 평가 77점은 무게가 완전히 달라요.
5. **평론 vs 커뮤니티 갭 즐기기:** xperiment처럼 Pitchfork 5.0인데 차트 7위인 작품이 제일 공부가 많이 돼요. "왜 갈리는가?"를 3줄로 써보기.
