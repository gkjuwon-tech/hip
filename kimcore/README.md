# 김코어 (KimCore): 지식 0, 규칙 0에서 출발하는 자기 개선 추론기

말은 못 하지만 추론은 하는 작은 코어. 거대 모델처럼 데이터를 먹지 않고, **스스로 문제를 내고, 풀고, 검증하고, 거기서 개념을 발명해** 성장하는 것이 목표다.

모든 버전은 CPU 4코어에서 몇 분~수십 분이면 돈다 (GPU 불필요).

## 실행 방법

```bash
python3 code/v5.py          # 환경변수 V5_SEED, V5_GENS
python3 code/v6.py          # V6_SEED, V6_GENS, V6_WORLDS
python3 code/v65.py         # v6.py를 import
python3 code/v7.py          # ARC 데이터 필요: git clone https://github.com/fchollet/ARC-AGI, ARC_DIR=.../ARC-AGI/data
python3 code/v81.py         # V8_SEED, V8_GENS, V8_TASKS, V8_PROBE_N
python3 code/v9.py          # v9base.py를 import. V9_SEED, V9_GENS, V9_TASKS
```

필요 패키지: `numpy`, `torch` (CPU), `sympy` (v4.5/v4.6/v5 일부). `code/lean_rsi_mathlib.py`는 Lean 4 + Mathlib을 스스로 설치한다.

## 정직성 장치 (모든 버전 공통 원칙)

- **대조군:** 같은 엔진, 학습 0회. 성장은 항상 대조군 대비로만 주장한다.
- **숨겨진 시험:** 학습/모델 선택에 쓰지 않는 고정 문제.
- **함정 문제:** 정당한 규칙으로는 원리상 풀 수 없는 문제 (우주 대입으로 증명). 풀리면 BREACH.
- **과적합 카운터:** 보이는 예시는 맞고 숨긴 예시에서 틀린 경우.
- **가짜 성장 감시:** 개념 수/층수/압축률은 보조 지표. 판정은 고정 탐침과 과거의 나 대결로만.
